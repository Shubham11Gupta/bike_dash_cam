# Bike Dashcam Hardware Requirements

## Current status

This document is intentionally a placeholder in Milestone 1.

## What is known today

- The project is intentionally software-first.
- No measured CPU, RAM, encoder, storage throughput, storage capacity, thermal, or power data has been collected yet in this repository.
- No embedded SoC or development board has been selected.

## What will populate this document later

- CPU utilization under single-camera and dual-camera workloads.
- RAM usage during steady-state capture and recording.
- Encoder requirements for the target H.264 pipeline.
- Storage throughput and capacity measurements for segmented recording.
- Camera interface requirements derived from real capture tests.
- Estimated power requirements from measured software behavior.

## Rule

Do not treat any hardware requirement as verified until it is backed by measured POC-1 data.
